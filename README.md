# Funniest Time Machine Warning

One-line warning label for a time machine, written like a genuine safety notice — with the punchline saved for the last words.

> WARNING: Never meet your past self. If you do, do not shake hands — one of you will vanish, and HR cannot say which.

The entry is 118 characters, inside the 120-character limit. The joke turns a real time-travel hazard (meeting your own past self, a paradox, a duplicate) into the warning itself, and keeps a straight face until the end.

## Run

```sh
node main.ts
```

This writes the label to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set). The output is fully deterministic: the same label, byte for byte, on every run. The program also refuses to write if the label ever falls outside the 1–120 character gate.

## Files

- `main.ts` — builds the label and writes `entry.txt`
- `prompt.txt` — the task description this entry was written from
